# AluConecta

AluConecta es una plataforma para conectar profesionales y empresas de la construcción con carpinterías de aluminio.

Los profesionales pueden publicar proyectos y recibir el interés de carpinterías registradas. Luego deciden cuáles autorizar para acceder al contacto, la documentación del proyecto y el envío de cotizaciones.

Las carpinterías pueden consultar oportunidades disponibles, manifestar interés y cotizar los proyectos para los que fueron autorizadas.

## Flujo principal

1. El profesional o empresa publica un proyecto.
2. Las carpinterías manifiestan interés.
3. El propietario del proyecto autoriza las carpinterías seleccionadas.
4. Se habilitan el contacto y la documentación correspondiente.
5. Las carpinterías autorizadas envían sus cotizaciones.
6. El profesional compara las propuestas recibidas.

## Tecnología

- Frontend HTML, CSS y JavaScript.
- Supabase para autenticación, base de datos y almacenamiento.
- RLS y RPC para control de acceso y protección de datos.
- Vercel para publicación del sitio.
- GitHub como repositorio de código.
